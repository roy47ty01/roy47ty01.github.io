watch-sync

A personal, single-user tool that copies its owner's own health data out of Google Health and into a private repository.

What it does

An app on the owner's Google Pixel Watch records sleep, steps and heart rate and sends it to Google. This tool authenticates as the owner with Google OAuth and reads that data back through the Google Health API on a schedule, so it can be reviewed and kept over time.

Who can use it

One person: the account owner. There is no sign-up, no other users, and no data belonging to anyone else is accessible. The tool is not distributed or offered as a service.

Permissions it requests

  • googlehealth.activity_and_fitness.readonly — steps and workouts
  • googlehealth.sleep.readonly — sleep sessions and stages
  • googlehealth.health_metrics_and_measurements.readonly — heart rate

Read-only. The tool cannot modify or delete anything in Google Health.

Privacy

How the data is stored and what is never done with it is set out in the privacy policy. In short: it stays in a private repository only the owner can access, and it is never shared or sold.
